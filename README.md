# Эгида

Система управления задачами и этапами работы отделов: канбан-доски, сроки, ответственность и отчёты — аналог Trello/Jira/Kaiten для локальной сети.
Один исполняемый файл для Linux (Astra Linux 1.7/1.8, Debian, Ubuntu) и Windows 10/11.

Автор: Горшков Сергей Владимирович — [nookbat.ru](https://nookbat.ru/)

## Возможности

- Доски с колонками-этапами, шаблоны досок, архив; перетаскивание карточек мышью.
- Задачи: описание, приоритет, срок, ответственный, соисполнители, наблюдатели, теги, чек-лист, комментарии с `@упоминаниями`, вложения, полная история изменений, копирование между досками.
- Отделы, пользователи (может состоять в нескольких отделах) и 4 роли: администратор, руководитель, исполнитель, наблюдатель.
- Уведомления в программе (назначение, перемещение, комментарий, упоминание, приближение срока) и по e-mail (SMTP).
- Поиск по всем доскам, быстрые фильтры «Мои», «Просроченные», «Без исполнителя», «Высокий приоритет».
- Аналитика: итоги, % просрочки, среднее время выполнения, графики по этапам, приоритетам, дням и исполнителям, разрезы по отделам и сотрудникам; выгрузка в CSV и Excel (XLSX).
- Журнал аудита, резервное копирование и восстановление.
- Светлая и тёмная тема, интерфейс на русском, английском и китайском.
- Изменения коллег появляются у всех автоматически (опрос каждые 2 с).

## Режимы работы

| Режим | Где данные | Когда выбирать |
|---|---|---|
| **Этот компьютер — сервер** | SQLite-файл на компьютере, где запущена программа | Небольшой отдел без выделенного сервера. Программа поднимает сервер на порту 8080, коллеги подключаются по IP или кнопкой «Найти в сети» (UDP 8089). |
| **Подключиться к серверу «Эгиды»** | На другом рабочем месте или выделенном сервере | Рабочие места коллег. При потере связи — «только просмотр» или «ждать подключения» (меню «Вид»). |
| **База данных PostgreSQL** | PostgreSQL 14+ | Несколько отделов, централизованное хранение и резервное копирование средствами СУБД. |
| **Сервер без окна** (`egida --serve`) | SQLite или PostgreSQL | 50+ пользователей: клиенты подключаются к серверу «Эгиды» через HTTP API. |

### Сервер без окна

```bash
# SQLite; при первом запуске с пустой базой нужно создать администратора
egida --serve --db /var/lib/egida/egida.db --listen :8080 --admin admin:пароль
# PostgreSQL
egida --serve --pg "postgres://egida:пароль@localhost:5432/egida?sslmode=disable" --listen :8080
```

Пакет `.deb` содержит службу systemd: параметры задаются в `/etc/default/egida`, запуск — `sudo systemctl enable --now egida`.

Флаги: `--serve`, `--db`, `--pg`, `--listen`, `--name` (имя сервера в сети), `--admin login:password`, `--version`.

## Установка

Файлы — на странице [релизов](https://github.com/Serge-Nook/aegis/releases).

- **Astra Linux / Debian / Ubuntu:** `sudo apt install ./egida_1.0.0_amd64.deb`. Для китайского интерфейса нужен шрифт с иероглифами (`fonts-noto-cjk` или `fonts-wqy-microhei`).
- **Любой Linux (AppImage):** `chmod +x Egida-1.0.0-x86_64.AppImage && ./Egida-1.0.0-x86_64.AppImage`. Меню «Файл → Установить в систему» копирует программу в `~/Applications` и добавляет ярлык в меню приложений; «Удалить из системы» убирает их (данные остаются).
- **Windows 10/11:** `Egida-1.0.0-Setup.exe` (ярлыки, правило брандмауэра для режима «сервер», удаление через «Приложения») или `Egida-1.0.0-portable.zip`. Если на компьютере нет OpenGL 2.1 (нет драйвера видеокарты, RDP, виртуальная машина), программа сама перезапускается с программным рендерером Mesa из папки `mesa`. Принудительно: `EGIDA_GL=software`.

Данные и журнал: Linux — `~/.config/Egida/`, Windows — `%APPDATA%\Egida\` (`egida.db`, `egida.log`).

## Сборка

```bash
go test ./...
go build -o egida .               # Linux: нужны gcc, libgl1-mesa-dev, xorg-dev
./packaging/release.sh            # .deb + AppImage (в Docker debian:buster) и Windows Setup.exe/zip → dist/
```

Для Windows-сборки нужны `gcc-mingw-w64-x86-64`, `nsis`, `p7zip-full`, `zip`. Интеграционные тесты PostgreSQL: `AEGIS_TEST_PG="postgres://…" go test ./internal/core/`.
